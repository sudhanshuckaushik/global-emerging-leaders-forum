=============================
Last updated: 2026-07-12

WHAT THIS PROJECT IS
--------------------
A reproducible studio system for building visually-similar client sites.
The GELFD 2026 forum is the first test site. Two things live here:

  main branch          → the original hand-built site: one 3.2 MB index.html
                         (navy/gold editorial identity, 23 base64 images).
  astro-starter branch → the reusable Astro template, re-skinned to the
                         GELFD brand-kit (neon / duotone / animated shaders).


ARCHITECTURE (the reproducible part)
------------------------------------
Three layers, swap per client, components stay put:

  1. TOKENS   brand-kit/ + src/styles/tokens.css   (derived from tokens.json)
  2. COMPONENTS  src/components/**                  (reused unchanged)
  3. CONTENT  src/data/site.ts + src/content/blog/  (the words)

New client = swap brand-kit + tokens.css + site.ts. Bootstrap via `npx degit`.
